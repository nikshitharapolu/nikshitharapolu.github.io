02
Information retrievalSecure RAGLive

Hybrid Search & Secure RAG Platform

Search that understands both keywords and meaning, then backs every answer with cited evidence. I wanted more than another RAG demo, so it checks its own results, retries once if they look weak, and says "I don't have enough information" instead of guessing.

  • Fuses BM25 ranking with 384-dimensional MiniLM embeddings and evaluates retrieval quality using NDCG@10 and Recall@10.
  • Supports PDF, TXT, and Markdown ingestion, overlapping chunks, persistent embedding caching, duplicate detection, prompt-injection protection, and validated fallback responses.
  • A LangGraph workflow, with a local Ollama model connected through LangChain, checks the evidence, rewrites a weak search and tries again once, then answers with citations or abstains. The app shows every step it took.
  • Compared the original and guided versions on 18 labeled questions and 19 automated tests pass.
  • Runs through FastAPI and Streamlit, with Docker Compose, local Kubernetes orchestration, Databricks vector analysis, and Terraform-provisioned S3-compatible storage and least-privilege IAM.
384D MiniLM embeddings 6/6 sandbox checks passed

Python · FastAPI · BM25 · Sentence Transformers · LangChain · LangGraph · Ollama · Docker · Kubernetes · Terraform · Moto · Databricks
